# Phase Tracker 관리

## 목적
docs/PHASE_TRACKER.md 파일을 통해 프로젝트 진행 상황을 체계적으로 관리한다.

## 사용 시점

### Phase 시작 시
1. docs/PHASE_TRACKER.md에서 해당 Phase 상태를 "🔄 진행 중"으로 변경
2. 해당 Phase의 가설과 성공 기준을 사용자에게 확인
3. 구현 체크리스트의 첫 번째 항목부터 시작

### 구현 항목 완료 시
1. 체크리스트에서 `- [ ]`를 `- [x]`로 변경
2. 관련 면접 포인트가 있으면 해당 섹션에 추가
3. 트러블슈팅이 발생했으면 블로그 소재 섹션에 추가

### Phase 완료 시
1. 상태를 "✅ 완료"로 변경
2. "실제 결과" 섹션에 실측치 기록 (예상치와 비교)
3. 성공 기준 체크리스트 업데이트
4. 면접 포인트 최종 정리
5. "누적 의사결정 로그" 테이블에 해당 Phase 결정 사항 추가

### 의사결정 발생 시
"누적 의사결정 로그" 테이블에 추가:
```
| 날짜 | Phase | 결정 사항 | 대안 | 선택 근거 |
```

### 트러블슈팅 발생 시
"트러블슈팅 히스토리" 테이블에 추가:
```
| 날짜 | Phase | 문제 | 원인 | 해결 | 블로그 작성 여부 |
```

## 주의사항
- IMPORTANT: "실제 결과" 섹션에는 실측치만 기록. 예상치를 실측치로 적지 않기.
- 성공 기준을 못 만족한 경우에도 정직하게 기록하고 원인 분석 추가.
